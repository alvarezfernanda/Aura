# Aura

Bienestar con contexto total — PWA React.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre http://localhost:5173

## Build de producción

```bash
npm run build
```

Genera carpeta `dist/` lista para deploy.

## Deploy en Vercel

1. Push este repo a GitHub
2. Entrá a vercel.com y "Import Project"
3. Vercel detecta Vite automáticamente
4. Click "Deploy"

## Instalación como app en Android

1. Abrí la URL de Vercel en Chrome
2. Menú ⋮ → "Añadir a pantalla principal"
3. Listo
